# AgendaPro

Base inicial de um sistema SaaS de agendamento para clínicas, consultórios, barbearias, salões e outros negócios.

## Stack

- Next.js
- TypeScript
- Supabase
- Vercel

## Variáveis de ambiente

Crie as variáveis abaixo na Vercel e no ambiente local:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

## Estrutura inicial

- `/` página inicial
- `/admin` painel administrativo
- `/agendar` área pública de agendamento

Próximas etapas: banco multiempresa, autenticação, profissionais, serviços, clientes e agenda.
